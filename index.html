Privacy policy: The Long Answer analytics tool

Last updated 24 November 2026.

"Long Answer Analytics" is a private tool used only by the owner of the YouTube channel The Long Answer (youtube.com/@longanswerexplained). It signs in with Google OAuth to read that channel's own YouTube Analytics and YouTube Data (views, retention, impressions, comments) and to manage that channel's own videos (titles, descriptions, scheduling).

It does not access any other user's data, does not sell, share or transfer data to anyone, and does not use it for advertising. Data is stored only on the owner's private computers to produce reports for improving the channel's videos, and can be deleted at any time. Access can be revoked at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
